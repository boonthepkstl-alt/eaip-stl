# สร้างงานใหม่และมอบหมายให้ทีม

## บทนำ

เอกสารนี้กำหนดความต้องการสำหรับความสามารถพื้นฐานของบทบาท **Staff** ในการสร้างงาน (Task) ใหม่และมอบหมายงานนั้นให้กับสมาชิกในทีม/โครงการที่ตนสังกัด ถือเป็น core flow ของระบบจัดการงานภายในโครงการ และเป็นเอกสาร requirement spec ฉบับแรกของโปรเจกต์นี้

## ขอบเขต

- ครอบคลุมเฉพาะการ **สร้างงานใหม่** และ **การมอบหมายงาน** โดยบทบาท Staff เท่านั้น
- การมอบหมายงานจำกัดเฉพาะสมาชิกภายในทีม/โครงการเดียวกันกับที่ Staff ผู้สร้างงานสังกัดอยู่ (Project-level scope) ไม่ครอบคลุมการมอบหมายข้ามทีม/โครงการ
- Staff สามารถมอบหมายงานให้ตนเองได้ (self-assign) ถือเป็นกรณีปกติ
- เนื้อหารายละเอียดงาน (Task detail) จัดเก็บเป็น Rich Text ในฐานข้อมูล ตามรูปแบบการจัดเก็บ Task ของระบบ (แยกจาก Project Doc/Wiki ที่เป็น Markdown ผูก Git)
- ไม่ครอบคลุมเรื่องการอนุมัติงานจากหัวหน้าทีม/Supervisor (ดู [[20260815-02-supervisor-task-approval]]), การแก้ไข/ลบงาน, Sub Task, หรือ workflow เปลี่ยนสถานะงานภายหลังการสร้าง — ประเด็นเหล่านี้ให้พิจารณาเป็น requirement แยกในอนาคต
- ยังไม่ผูก tech stack หรือรายละเอียดการ implement ใดๆ ให้เป็นไปตาม `technology-stack.md` เมื่อมีการตัดสินใจจริง

## Functional Requirements (FR)

| รหัส | ความต้องการ | รายละเอียด | ระดับความสำคัญ |
|------|--------------|-------------|------------------|
| FR-01 | สร้างงานใหม่ | Staff สามารถสร้างงานใหม่ได้ โดยระบุฟิลด์อย่างน้อยดังนี้: ชื่องาน, รายละเอียด (Rich Text), ผู้รับมอบหมาย, กำหนดส่ง (Due Date), ระดับความสำคัญ (Priority) และระบบกำหนดสถานะเริ่มต้นของงานให้อัตโนมัติเมื่อสร้างเสร็จ (เช่น สถานะ "รอดำเนินการ") | สูง |
| FR-02 | มอบหมายงานภายในทีม/โครงการเดียวกัน | Staff สามารถมอบหมายงานที่สร้างขึ้นให้กับสมาชิกคนอื่นที่อยู่ในทีม/โครงการเดียวกันกับตนได้เท่านั้น ระบบต้องตรวจสอบว่าผู้ถูกมอบหมายเป็นสมาชิกของทีม/โครงการเดียวกันก่อนบันทึกการมอบหมายทุกครั้ง | สูง |
| FR-03 | มอบหมายงานให้ตนเอง (Self-assign) | Staff สามารถมอบหมายงานที่ตนสร้างขึ้นให้กับตนเองได้ โดยระบบต้องอนุญาตกรณีนี้เป็นปกติ ไม่ถือเป็นข้อผิดพลาดหรือถูกจำกัดสิทธิ์ | สูง |

## Non-Functional Requirements (NFR)

| รหัส | ด้าน | ความต้องการ |
|------|------|--------------|
| NFR-01 | ความปลอดภัย/สิทธิ์การใช้งาน (Authorization) | ระบบต้องบังคับใช้กฎการตรวจสอบสิทธิ์ตาม FR-02 อย่างเคร่งครัดในทุกช่องทางที่เรียกใช้งานการมอบหมายงาน โดยปฏิเสธคำขอมอบหมายงานให้ผู้ใช้ที่ไม่ได้อยู่ในทีม/โครงการเดียวกันทุกกรณี |
