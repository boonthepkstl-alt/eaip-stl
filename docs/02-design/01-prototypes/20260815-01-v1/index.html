รวมหน้าจอ Prototype

แปลงจาก docs/02-design/feature-list.md และ docs/02-design/user-journey.md ยึด Design System ตาม docs/02-design/DESIGN.md ครอบคลุมทั้ง 2 journey (Staff และ Supervisor) — เริ่มต้นที่หน้า เข้าสู่ระบบ

Journey 1: Staff สร้างงานใหม่และมอบหมายงานให้ทีม Staff

เข้าสู่ระบบ จุดเริ่มต้นของทั้งสอง journey เลือกบทบาทเพื่อจำลอง (demo) จุดเริ่ม journey — ไม่มีรหัส FR เจาะจง Staff: รายการงานของฉัน Dashboard สรุปสถานะงาน + ทางเข้าสู่การสร้างงานใหม่ FR-01 (จุดเริ่ม), แสดงผล FR-04/05/06 Staff: สร้างงานใหม่ ฟอร์มสร้างงาน + มอบหมายงาน (self-assign/สมาชิกทีม) + ตัวอย่าง error state FR-01, FR-02, FR-03, NFR-01

Journey 2: Supervisor ตรวจสอบและอนุมัติ/ปฏิเสธงาน Supervisor Staff

Supervisor: รายการงานรออนุมัติ รายการงานที่รออนุมัติ เฉพาะทีม/โครงการที่ดูแล FR-04 (จุดรับแจ้งเตือน), NFR-02 Supervisor: อนุมัติ/ปฏิเสธงาน รายละเอียดงาน + ปุ่มอนุมัติ/ปฏิเสธ พร้อม modal ระบุเหตุผล FR-05, FR-06, NFR-02 Supervisor: ถูกปฏิเสธสิทธิ์ ตัวอย่างเมื่อ Supervisor พยายามอนุมัติ/ดูงานนอกทีม/โครงการที่ดูแล NFR-02 Staff: รายละเอียดงาน (ผลการอนุมัติ) มุมมอง Staff เห็นเหตุผลที่ถูกปฏิเสธ + ทางเข้าสู่การแก้ไข FR-04 (แสดงผล), FR-05/06 (แสดงผล), จุดเข้า FR-07 Staff: แก้ไขและส่งขออนุมัติใหม่ แก้ไขงานที่ถูกปฏิเสธแล้วส่งกลับเข้าสถานะ "รออนุมัติ" FR-07
