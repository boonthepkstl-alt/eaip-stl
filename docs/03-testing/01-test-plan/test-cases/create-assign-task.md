อ้างอิง: [[feature-list#1. สร้างงานใหม่และมอบหมายงานให้ทีม]],

Precondition ร่วม: มีผู้ใช้บทบาท Staff อย่างน้อย 1 คน ("Staff A") สังกัดทีม/โครงการ "โครงการ X"
และมีสมาชิกอื่นอย่างน้อย 1 คน ("Staff B") สังกัด "โครงการ X" เช่นกัน มีผู้ใช้อีก 1 คน ("Staff C")
สังกัดทีม/โครงการอื่น ("โครงการ Y") ที่ไม่ใช่ "โครงการ X" มี Supervisor อย่างน้อย 1 คนสังกัด
"โครงการ X" (สำหรับตรวจสอบว่าได้รับ Notification ในขั้นตอนสุดท้าย)
