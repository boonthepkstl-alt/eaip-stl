# Test Case: แก้ไขงานที่ถูกปฏิเสธและขออนุมัติใหม่

อ้างอิง: [[feature-list#3. แก้ไขงานที่ถูกปฏิเสธและขออนุมัติใหม่]],
[[user-journey#Journey: Supervisor ตรวจสอบและอนุมัติ/ปฏิเสธงาน]],
[[acceptance-criteria#3. แก้ไขงานที่ถูกปฏิเสธและขออนุมัติใหม่]]

Precondition ร่วม: มีทีม/โครงการ "โครงการ X" มี Staff ("Staff A" ผู้สร้างงานเดิม, "Staff B" ผู้ถูก
มอบหมาย) และ Supervisor ("Supervisor S") สังกัดอยู่ มีทีม/โครงการอื่น "โครงการ Y" มี Staff อีกคน
("Staff C") ที่ไม่ได้สังกัดโครงการ X มีงาน (Task) ที่ Staff A สร้างและถูก Supervisor S ปฏิเสธแล้ว
อยู่ในสถานะ "ถูกปฏิเสธ" พร้อมเหตุผล (ต่อยอดจาก [[test-cases/supervisor-task-approval]] TC-02-05)
